# Sk Niyaz Noor - Portfolio

An Instagram-style portfolio website showcasing the work of **Sk Niyaz Noor** - a Software Engineer and Writer.

## 🌟 Features

- **Instagram Reel-Style Feed**: Vertical scrolling feed with smooth snap-to-section behavior
- **Search Functionality**: Real-time search with category filters (Projects, Writing, Skills, About)
- **Profile Page**: Complete profile with stats, bio, social links, and tabbed content
- **Responsive Design**: Optimized for both mobile and desktop devices
- **Dark Theme**: Instagram-inspired dark mode with beautiful gradients
- **Smooth Animations**: Engaging micro-animations and transitions

## 🚀 Tech Stack

- **Framework**: Next.js 16 with TypeScript
- **Styling**: Tailwind CSS with custom Instagram-inspired design system
- **Icons**: Lucide React
- **Font**: Inter (Google Fonts)

## 📦 Installation

```bash
cd frontend
npm install
```

## 🏃‍♂️ Running the Application

```bash
cd frontend
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 📱 Pages

- **Feed (`/`)**: Instagram Reel-style vertical scrolling feed
- **Search (`/search`)**: Search and filter posts by category
- **Profile (`/profile`)**: Profile page with stats, bio, and posts grid

## 🎨 Design Features

- Custom Instagram-inspired color palette
- Glassmorphism effects
- Gradient text and backgrounds
- Smooth scroll animations
- Responsive navigation (bottom bar on mobile, top bar on desktop)
- Card hover effects
- Tag system for categorization
